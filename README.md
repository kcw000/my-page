# Kai Creative Works

コピーライター / Web・LPクリエイターとして、言葉を起点にブランドとWebの伝わり方を設計する個人クリエイターの営業LPです。

まとまっていない想いやサービスの魅力を整理し、コピー、構成、デザイン、Webまで一貫して形にすることを主軸にしています。

公開URL: `https://kcw000.github.io/my-page/`

## 使用技術

- HTML
- CSS
- JavaScript

ビルド環境、CMS、外部ライブラリ、CDNは使用していません。

## AIツール活用方針

情報整理、構成案の検討、ビジュアル制作、Web実装、簡易BGM制作などに、必要に応じてAIツールを活用します。

ただし、ヒアリング、コンセプト設計、コピーライティング、構成、表現の方向性、修正、最終確認は制作者本人が行います。クライアントから預かった機密情報・個人情報は、事前確認なく外部AIサービスへ入力しません。

6. 成功メッセージが表示されることを確認
7. フォームがリセットされることを確認
8. Formspree管理画面でSubmissionを確認
9. 通知先メールに届くことを確認

### GitHub Pages

ビルド処理は不要です。`main` ブランチのリポジトリ直下をGitHub Pagesの公開元に設定しています。

1. GitHub上に公開用リポジトリを作成
2. ローカルリポジトリへ `origin` を設定
3. `main` ブランチをpush
4. GitHubの `Settings > Pages` を開く
5. `Deploy from a branch` を選択
6. Branchを `main`、フォルダを `/ (root)` に設定
7. 発行された公開URLでトップページと `privacy.html` を確認

`index.html` の `canonical`、`og:url`、`og:image`、`twitter:image` と、`privacy.html` の `canonical` は公開URLに合わせて設定済みです。ユーザー名、リポジトリ名、公開URLを変更した場合はすべて同時に更新してください。
